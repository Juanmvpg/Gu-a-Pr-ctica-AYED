# Guía Práctica AYED

Guía de ejercicios prácticos de **Algoritmos y Estructuras de Datos** en C++.

Construida de forma incremental durante el proceso de aprendizaje.

## Contenido actual

| Archivo | Tema |
|---------|------|

## Cómo usar la guía

Cada ejercicio está comentado en un bloque `/* */`.  
Para trabajar un ejercicio:
1. Copiá el bloque del ejercicio a un archivo `.cpp` nuevo.
2. Eliminá los delimitadores `/*` y `*/`.
3. Compilá y ejecutá para verificar tu solución.

## Reglas generales

- No usar corchetes `[]` dentro de las funciones pedidas (salvo indicación).
- Solo aritmética de punteros: `*(arr + i)`, `ptr++`, `ptr--`, etc.
